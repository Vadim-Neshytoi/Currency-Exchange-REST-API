# Currency Exchange REST API

## Описание проекта

**Currency Exchange REST API** — учебный backend-проект, реализующий REST API для хранения валют,
управления обменными курсами и конвертации денежных сумм.

Приложение поддерживает локальный запуск, а также развертывание через Docker на удаленном сервере.

---

## Основные возможности

Проект предоставляет REST API для:

- получения списка валют;
- получения информации о конкретной валюте;
- добавления новой валюты;
- получения списка обменных курсов;
- получения конкретного обменного курса;
- добавления нового обменного курса;
- обновления существующего обменного курса;
- конвертации денежных сумм между валютами.

При выполнении конвертации автоматически используется один из трёх сценариев:

- прямой обменный курс;
- обратный обменный курс;
- кросс-курс через USD.

# Архитектура проекта

Проект построен по многослойной архитектуре с разделением ответственности между слоями.


HTTP Request
│
▼
SimpleHandler
│
▼
Controller
│
▼
DatabaseManager
│
▼
SQLite
▲
│
Domain Models


## Ответственность слоев

### Handler

Отвечает за:

- обработку HTTP-запросов;
- разбор URL и параметров;
- валидацию HTTP-запросов;
- формирование HTTP-ответов;
- сериализацию объектов в JSON.

---

### Controller

Отвечает за:

- реализацию бизнес-логики;
- взаимодействие с DatabaseManager;
- выбор сценария конвертации;
- преобразование ошибок базы данных в бизнес-исключения.

---

### DatabaseManager

Отвечает за:

- выполнение SQL-запросов;
- работу с SQLite;
- создание объектов моделей;
- отсутствие бизнес-логики.

---

### Domain Models

Проект содержит модели предметной области:

- Currency
- ExchangeRate
- ExchangeResult

Каждая модель отвечает за:

- хранение собственного состояния;
- валидацию входных данных;
- инкапсуляцию через `property`;
- преобразование объекта в словарь (`to_dict()`).

---

### Exceptions

Пользовательские исключения, обеспечивающие взаимодействие между слоями приложения.

---

# Особенности реализации

В проекте реализованы следующие архитектурные решения:

- многослойная архитектура;
- использование объектов предметной области между слоями;
- отсутствие передачи словарей между слоями;
- инкапсуляция моделей;
- использование пользовательских исключений;
- использование `Decimal` для денежных вычислений;
- округление денежных значений согласно требованиям;
- валидация данных внутри моделей;
- использование ограничений SQLite (`UNIQUE`);
- поддержка внешних ключей (`FOREIGN KEY`);
- полная типизация проекта с помощью type hints;
- контейнеризация приложения с помощью Docker;
- сохранение SQLite базы данных через Docker volume.

# Получение проекта

Клонировать репозиторий:

```bash
git clone https://github.com/Vadim-Neshytoi/Currency-Exchange-REST-API.git

cd Currency-Exchange-REST-API
Запуск проекта
Запуск напрямую через Python

Запустить сервер:

python main.py

или:

python3 main.py

После запуска REST API будет доступно:

http://localhost:8000
Запуск через Docker

Собрать образ и запустить контейнер:

docker compose up --build -d

Проверить состояние контейнера:

docker ps

После запуска API будет доступно:

локально:

http://localhost:8000

на удаленном сервере:

http://<server-ip>:8000

Остановить приложение:

docker compose down
Работа с базой данных в Docker

SQLite база данных хранится в отдельном Docker volume.

Это позволяет сохранять данные при пересоздании контейнера:

docker compose down

docker compose up -d

После повторного запуска все ранее созданные валюты и обменные курсы сохраняются.

Деплой

Backend API развернут на VPS с использованием Docker Compose.

Рабочий экземпляр API:

http://139.100.235.91:8000

Для проверки API можно использовать:

Postman;
curl;
Insomnia;
любой HTTP-клиент.
Проверка работы API

REST API
Метод	Endpoint	Назначение
GET	/currencies	Получить список валют
GET	/currency/{code}	Получить валюту по коду
POST	/currencies	Добавить валюту
GET	/exchangeRates	Получить список обменных курсов
GET	/exchangeRate/{pair}	Получить обменный курс
POST	/exchangeRates	Добавить обменный курс
PATCH	/exchangeRate/{pair}	Обновить обменный курс
GET	/exchange?from={code}&to={code}&amount={value}	Выполнить конвертацию
Примеры запросов
Получение списка валют
GET /currencies
